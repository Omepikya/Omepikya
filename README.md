A personal finance platform focused on expense tracking, budgets, savings goals, analytics, and useful financial insights.

**Stack:** Java · Android · Supabase · SQLite · Cloud Storage

### 🌐 Omepikya Web
The Omepikya web platform, built with a focus on performance, responsiveness, and usability.
